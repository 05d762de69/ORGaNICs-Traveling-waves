# ORGaNICs-Traveling-waves
Project towards building a generalised model for traveling waves using ORGaNICs. We make use of the model for perceptual waves using binocular rivalry from Cardoso et al. 2025

# Example Notebook.ipynb 
is the notebook for running of the project where the reproduction of results for binocular rivalry and the novel flow of attention is demonstrated.

# BinocularRivalryWavesORGaNICs_vers1.py
The file with the main model implemented using ORGaNICs
